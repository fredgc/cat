2. Immediate Next Steps (Milestone 2 Execution Plan)

Step 2.1: Implement Phantom Model (lib/models/phantom.dart)

  • Define PhantomDisk representing a circular disk phantom:

    • Center coordinates: (x0,y0)(x_0, y_0), default (0.2,0.3)(0.2, 0.3) to match the original Java applet.

    • Radius: rpr_p, default 0.10.1.

    • Attenuation density: default 1.01.0.

  • Method double chordLength(double r, double cosTheta, double sinTheta):

    • Evaluates distance to line: sc=x0cos⁡θ+y0sin⁡θs_c = x_0 \cos\theta + y_0 \sin\theta, Δs=r−sc\Delta s = r - s_c.

    • Returns 2rp2−(Δs)22\sqrt{r_p^2 - (\Delta s)^2} if |Δs|<rp|\Delta s| < r_p, else 0.00.0.

  • Support translation (x0,y0)(x_0, y_0) bounded within [−0.8,0.8][-0.8, 0.8].

Step 2.2: Implement Mathematical Engine (lib/models/radon_engine.dart)

  • Discretization grid:

    • Angle samples: 2P2P (default P=50⟹100P = 50 \implies 100 angles), θj=πj/P\theta_j = \pi j / P for j∈{0,…,2P−1}j \in \{0, \dots, 2P - 1\}.

    • Radial samples: 2Q2Q (default Q=50⟹100Q = 50 \implies 100 samples), ri=(i−Q)/Qr_i = (i - Q)/Q for i∈{0,…,2Q−1}i \in \{0, \dots, 2Q - 1\}, step h=1/Qh = 1/Q.

  • Lookup tables:

    • Precompute cos⁡(θj)\cos(\theta_j) and sin⁡(θj)\sin(\theta_j) for all 2P2P angles.

    • Precompute centered disk profile ψ[i]\psi[i] for 4Q4Q radial points:

      ψ[i]=2rp2−s2where s=(i−2Q)/Q\psi[i] = 2\sqrt{r_p^2 - s^2} \quad \text{where } s = (i - 2Q)/Q

  • Natterer ramp filter kernel wb(l)w_b(l) (Natterer Eq. 1.23, p. 111):

    wb(l)=b2π4(1−4l2),b=πQ,l∈ℤw_b(l) = \frac{b^2}{\pi^4(1 - 4l^2)}, \quad b = \pi Q, \quad l \in \mathbb{Z}

  • Filtered disk profile wψ[k]w\psi[k]:

    wψ[k]=h∑l=04Q−1ψ[l]⋅wb(k−l)w\psi[k] = h \sum_{l = 0}^{4Q - 1} \psi[l] \cdot w_b(k - l)

  • Fast sinogram generation:

    • Unfiltered sinogram lookup: g(ri,θj)=ψ[Q+i−round(Q⋅sc)]g(r_i, \theta_j) = \psi[Q + i - \text{round}(Q \cdot s_c)].

    • Filtered sinogram lookup: gfiltered(ri,θj)=wψ[Q+i−round(Q⋅sc)]g_{\text{filtered}}(r_i, \theta_j) = w\psi[Q + i - \text{round}(Q \cdot s_c)].

  • Active probe modes:

    • ProbeMode.none: No active selection.

    • ProbeMode.point: Point (xp,yp)(x_p, y_p) selected in object space →\to sinusoid r(θj)=xpcos⁡θj+ypsin⁡θjr(\theta_j) = x_p \cos\theta_j + y_p \sin\theta_j.

    • ProbeMode.line: Line (rs,θk)(r_s, \theta_k) selected in sinogram →\to line xcos⁡θk+ysin⁡θk=rsx\cos\theta_k + y\sin\theta_k = r_s and origin normal.

    • ProbeMode.theta: Constant angle θk→\theta_k \to family of parallel lines across all rr.

    • ProbeMode.sline: Constant offset rs→r_s \to family of lines tangent to circle of radius |rs||r_s|.

  • 1D Slice Extraction & Backprojection Integral:

    • Compute 1D profile array f[j]f[j] along the active trajectory.

    • Compute the backprojection integral:

      Integral=12P∑j=02P−1f[j]\text{Integral} = \frac{1}{2P} \sum_{j=0}^{2P - 1} f[j]

    • When filtered, returns ≈1.0\approx 1.0 inside the phantom disk, and ≈0.0\approx 0.0 outside.
