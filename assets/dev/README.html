CAT Scan Demonstration Tool

An interactive, educational application for visualizing the mathematics and physics behind Computed Axial Tomography (CAT / CT scans) and the Radon Transform.

This project modernizes and enhances an educational Java demonstration applet originally created by Fred Gylys-Colwell in 1998 (last revised 2006) for a talk on the Radon transform (gchouse.org/CAT/talk.html).

1. Project Overview & Motivation

An X-Ray CAT scan generates a detailed 2D interior cross-section of an object or human body from the outside without invasive surgery. The machine sends X-ray beams through the body from all angles θ\theta and measures how much radiation is absorbed.

Mathematically, the physical attenuation satisfies the Beer-Lambert law:

I=I0exp⁡(−∫Lf(x,y)ds)⟹g(L)=−ln⁡(II0)=∫Lf(x,y)dsI = I_0 \exp\left(-\int_L f(x, y) \, ds\right) \implies g(L) = -\ln\left(\frac{I}{I_0}\right) = \int_L f(x, y) \, ds

where f(x,y)f(x, y) is the spatial absorption coefficient. This is equivalent to measuring line integrals over all straight lines traversing the object.

This application provides an intuitive, interactive environment to explore:

  • How 1D projection integrals combine across angles to form a 2D parameter dataset known as a sinogram g(r,θ)g(r, \theta).

  • The geometric duality between points in object space and sinusoidal trajectories in sinogram space.

  • Why unfiltered backprojection produces a blurry image (1/|r|1/|r| blur).

  • How high-pass filtering projections with Frank Natterer’s ramp filter kernel (wbw_b) sharpens the sinogram so that backprojection accurately reconstructs the exact interior attenuation values.

2. Mathematical Foundation

2.1 Parameterization of Lines & The Radon Transform

Every line Lr,θL_{r, \theta} in the 2D Cartesian plane is parameterized by:

  • θ∈[0,2π)\theta \in [0, 2\pi): the angle of the normal vector from the origin to the line.

  • r∈[−1,1]r \in [-1, 1]: the signed perpendicular distance from the origin to the line.

The equation of the line is:

xcos⁡θ+ysin⁡θ=rx \cos\theta + y \sin\theta = r

The Radon Transform maps a 2D function f(x,y)f(x, y) in object space to sinogram space g(r,θ)g(r, \theta):

g(r,θ)=ℛ[f](r,θ)=∬ℝ2f(x,y)δ(xcos⁡θ+ysin⁡θ−r)dxdyg(r, \theta) = \mathcal{R}[f](r, \theta) = \iint_{\mathbb{R}^2} f(x, y) \, \delta(x \cos\theta + y \sin\theta - r) \, dx \, dy

2.2 Sinogram Duality & Geometry

  • Point in Object Space ↔\leftrightarrow Sinusoid in Sinogram Space: All lines passing through a fixed point (x1,y1)(x_1, y_1) satisfy:

    r(θ)=x1cos⁡θ+y1sin⁡θr(\theta) = x_1 \cos\theta + y_1 \sin\theta

As θ\theta varies from 00 to 2π2\pi, this traces an exact sinusoidal curve in (r,θ)(r, \theta) space.

  • Point in Sinogram Space ↔\leftrightarrow Line in Object Space: A single point (r0,θ0)(r_0, \theta_0) in sinogram space corresponds to a single line xcos⁡θ0+ysin⁡θ0=r0x \cos\theta_0 + y \sin\theta_0 = r_0 in object space.

  • Row of Sinogram (constant θ\theta): Represents a parallel beam of X-rays passing through the object at angle θ\theta across all radial offsets rr.

  • Column of Sinogram (constant rr): Represents lines tangent to a circle of radius |r||r| centered at the origin.

2.3 Phantom & Analytical Projections

To test reconstruction algorithms, a known mathematical object called a phantom is simulated. For a circular disk phantom of radius rpr_p centered at (x0,y0)(x_0, y_0) with uniform attenuation density 11:

  • The distance from the center (x0,y0)(x_0, y_0) to line Lr,θL_{r, \theta} is |Δs||\Delta s|, where:

    sc=x0cos⁡θ+y0sin⁡θ,Δs=r−scs_c = x_0 \cos\theta + y_0 \sin\theta, \quad \Delta s = r - s_c

  • If |Δs|<rp|\Delta s| < r_p, the chord length (line integral) is:

    ψ(Δs)=2rp2−(Δs)2\psi(\Delta s) = 2 \sqrt{r_p^2 - (\Delta s)^2}

Otherwise, ψ(Δs)=0\psi(\Delta s) = 0.

2.4 Backprojection & Frank Natterer’s Ramp Filter

Simple backprojection integrates the recorded projections over all angles:

funfiltered(x,y)=∫02πg(xcos⁡θ+ysin⁡θ,θ)dθf_{\text{unfiltered}}(x, y) = \int_0^{2\pi} g(x \cos\theta + y \sin\theta, \theta) \, d\theta

Because every projection point contributes energy across the entire line, unfiltered backprojection blurs features by a point spread function proportional to 1/|r|1/|r|.

To achieve exact reconstruction, projections must be filtered prior to backprojection (Filtered Backprojection, FBP). Using Frank Natterer’s discrete filter kernel wb(l)w_b(l) (The Mathematics of Computerized Tomography, Eq. 1.23, p. 111):

wb(l)=b2π4(1−4l2)(l∈ℤ)w_b(l) = \frac{b^2}{\pi^4 (1 - 4 l^2)} \quad (l \in \mathbb{Z})

where b=πQb = \pi Q, step size h=1/Qh = 1/Q, and QQ is the radial sampling resolution.

Convolving g(r,θ)g(r, \theta) with wbw_b along the radial coordinate yields the filtered sinogram:

gfiltered(r,θ)=(g*wb)(r,θ)=h∑l=−LLg(r−lh,θ)wb(l)g_{\text{filtered}}(r, \theta) = (g * w_b)(r, \theta) = h \sum_{l = -L}^{L} g(r - l h, \theta) \, w_b(l)

When the backprojection integral is computed on the filtered data:

∫02πgfiltered(xcos⁡θ+ysin⁡θ,θ)dθ≈{1.0if (x,y) is inside the phantom0.0if (x,y) is outside the phantom\int_0^{2\pi} g_{\text{filtered}}(x \cos\theta + y \sin\theta, \theta) \, d\theta \approx \begin{cases} 1.0 & \text{if } (x, y) \text{ is inside the phantom} \\ 0.0 & \text{if } (x, y) \text{ is outside the phantom} \end{cases}

4. Technology Stack & Key Features

  • Framework: Flutter (Dart 3) targeting Web and Android.

  • Dual Synchronized Viewports:

    • Object Space: Interactive 2D coordinate plane showing the object/phantom, active X-ray lines, and probe points.

    • Sinogram / Radon Space: 2D parameter plane (r,θ)(r, \theta) displaying attenuation values as an interactive heatmap, with probe cursors and sinusoidal curves.

  • 1D Profile & Backprojection Graph:

    • Live cross-sections of g(r,θ)g(r, \theta) along chosen angles θ\theta, radial offsets rr, or sinusoidal point trajectories.

    • Real-time calculation and display of the backprojection integral ∫02πg(xcos⁡θ+ysin⁡θ,θ)dθ\int_0^{2\pi} g(x\cos\theta + y\sin\theta, \theta) \, d\theta.

  • Fast Custom Painting: Hardware-accelerated 2D canvas painters (CustomPainter) and cached pixel buffers for smooth 60 FPS drag interactions.

  • Preferences: Local user settings (theme, colormaps, resolution, guides) stored via shared_preferences. No file manager or Google Drive storage required.

5. Getting Started & Running Locally

Prerequisites

  • Flutter SDK (3.13+ recommended)

  • Google Chrome (for web development)

  • make and Pandoc (for compiling documentation)

Forking and Cloning

  1. Fork the repository on GitHub to your account.

  2. Clone your fork locally:

    git clone https://github.com/<your-username>/cat.git
cd cat

  3. Install dependencies:

    flutter pub get

  4. Build documentation assets:

    make docs

Local Development Commands

  • Run web development server:

    ./run-local-server.sh

  • Run local release build:

    ./run-local-release.sh

  • Run automated test suite:

    flutter test

  • Analyze codebase:

    flutter analyze

  • Build documentation and icons:

    make ASSETS
